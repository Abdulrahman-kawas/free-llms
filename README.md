# free-llm

بيئة جاهزة لكل الموديلات المجانية (Gemini, Groq, Z AI, Ollama Cloud, Cloudflare) بمكان واحد،
منفصلة عن أي مشروع. إذا خلص موديل، بيتحول لحالو عاللي بعدو، أو بتختار انت من القائمة.

## الملفات

| الملف | شو فيه |
|---|---|
| `providers.toml` | المزودين، الموديلات، ترتيب التبديل (`order`)، الحدود. **بلا مفاتيح** |
| `.env` | المفاتيح بس (مش بـ git). شوف `.env.example` |
| `.state.json` | مين تعب اليوم، كم طلب انبعت، واختيارك (بيتعبى لحالو) |
| `free_llm/` | الكود: `router.py` (التبديل)، `server.py` (endpoint محلي)، `cli.py` |
| `tests/` | تستات بلا انترنت: `uvx --with-editable . pytest -q tests` |

## أول مرة

1. حط المفاتيح بـ `.env`، ومش لازم كلها. المزود اللي ما إلو مفتاح بينطنش.
2. `free-llm check` بيجرب كل مفتاح بطلب `/models`، وهاد ما بياكل من الكوتا.
3. `free-llm list` بيعرض القائمة: مين جاهز، وكم استعملت اليوم.

الأمر `free-llm` مركّب على الماك (`uv tool install -e .`)، فأي تعديل عالكود بيمشي فوراً.

## الاستعمال

```bash
free-llm list                 # القائمة، مرقّمة
free-llm use 3                # خلّي رقم 3 أول واحد بيجربو auto (أو use بلا رقم: بيسألك)
free-llm use auto             # رجّع الترتيب متل ما هو بـ providers.toml
free-llm ask "سؤال"           # auto: بيطبع الجواب ومين جاوب ومين انطنش وليش
free-llm ask "سؤال" -m groq:openai/gpt-oss-120b   # هاد بالزبط، بلا تبديل
free-llm ping 4               # "Say OK" لموديل واحد (بياكل طلب واحد)
free-llm reset                # انسى كل الاستراحات
free-llm serve                # endpoint محلي: http://127.0.0.1:8787/v1
```

## الربط مع أي مشروع

**Python:** `uv pip install -e ~/Desktop/free-llm` جوّا venv المشروع، وبعدين:

```python
from free_llm import Router, text_of
reply = Router().chat([{"role": "user", "content": "Hi"}], max_tokens=500)
print(text_of(reply), reply["x_free_llm"]["model"])
```

**أي لغة أو أداة بتحكي OpenAI:** شغّل `free-llm serve`، وحط بالمشروع:

```
base_url = http://127.0.0.1:8787/v1
api_key  = أي شي (أو FREE_LLM_PROXY_KEY إذا حطيتو)
model    = auto        (أو اسم من free-llm list)
```

**مشروع بدو ترتيب غير:** `FREE_LLM_CONFIG=/path/providers.toml`.
**سيرفر:** المتغيرات بالـ environment بتغلب على `.env`.

## كيف بيتبدل لحالو

auto بيبلّش باختيارك، وبعدين بيمشي على `order`. بيتجاوز أي موديل ما إلو مفتاح، أو بيرتاح، أو
مشغول (Z AI بيقبل طلب واحد بالمرة)، أو وصل `daily_limit` تبعو. وإذا فشل الطلب:

| الخطأ | الاستراحة |
|---|---|
| 429 كوتا اليوم (PerDay / RPD / neurons) | لنص الليل بتوقيت المزود (`reset_tz`) |
| 429 الحد الأسبوعي (Ollama) | لنص الليل، وبعدين بيرجع يجرب |
| 429 حد الجلسة (Ollama) | ساعة |
| 429 بالدقيقة | `Retry-After`، أو 60 ثانية |
| 5xx، timeout، ما في نت | 30 ثانية |
| 401/403 مفتاح غلط، 404 موديل مش موجود | 6 ساعات |
| 4xx غيرها | بلا استراحة، بيروح عاللي بعدو |

## انتبه

- **Gemini:** الحد 20 طلب باليوم لكل موديل، وعلى كل مشروع Google. إذا حطيت نفس المفتاح تبع
  موقع المحاضرات، فكل تجربة هون بتاكل من كوتا الطلاب. الأحسن تعمل مفتاح بمشروع Google تاني.
- العدّاد اللي هون بيعدّ بس الطلبات اللي طلعت من هالماك. الـ 429 هو اللي بيكشف الباقي.
- الموديلات المجانية ممكن تستعمل اللي بتبعتلها بالتدريب، فلا تبعت أسرار.
- `stream: true` بيوصل بقطعة وحدة، والبرامج اللي بتحكي OpenAI بتقبلها عادي.
